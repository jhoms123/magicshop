# Third-party asset notices

This starter bundles existing artwork and a font. No pixel-art images were generated for this project. Original pixel pixels were retained; the Kenney tiles in the atlases were repacked from individual source tiles for simpler runtime slicing.

## Kenney Tiny Town and Tiny Farm

- Artist: Kenney (www.kenney.nl).
- Packs: [Tiny Town](https://kenney.nl/assets/tiny-town) and [Tiny Farm](https://kenney.nl/assets/tiny-farm).
- License: Creative Commons Zero (CC0 1.0). Attribution is appreciated but not required.
- Bundled source-atlas copies: `Assets/Resources/Art/TinyTownAtlas.png` and `Assets/Resources/Art/TinyFarmAtlas.png`.
- Source files were obtained from [shorepine/kenney](https://github.com/shorepine/kenney), a mirror of Kenney's CC0 asset library. See the repository README and its linked license information.
